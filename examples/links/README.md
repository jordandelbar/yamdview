# Links between files

Run `cargo run -- examples/links/README.md`. Click a link, or press `Tab` to
pick one and `Enter` to follow it. `Backspace` goes back.

to open.

- A [missing file](nowhere.md).

## What stays with the terminal

Web links are still hyperlinks: with `--no-mouse`, your terminal opens them on
click. Back to [the top](#links-between-files).
